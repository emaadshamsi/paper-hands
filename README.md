# 🪙 PAPER HANDS

**Hold for more. Lose it all.** A one-button greed web game.

▶️ **Play:** https://emaadshamsi.github.io/paper-hands/

Hold (space / click / tap) to pump your multiplier — the longer you hold, the higher it
climbs and the more likely it all rugs. Release to bank it. One rug ends the run.

Single-file vanilla JS + Canvas, no engine, no deps. Part of an experiment in AI-driven work.
